FASTA or BAM files format for mutation IDs

WorkFlow use SnakeMake to run workflow

2. Quality Control (QC)
FASTQ QC: Use tools like FastQC to asses quality of RNA-seq reads
FASTA QC:  SeqKit to quality assessment of genomic sequences

Remove low quality reads/ adaptor sequences and contaminants with Trimmomatic or Cutadapt

Seq Alignment:

STAR for RNA-seq Alignment

Ouputs 
Aligned files in BAM format
Alignment statistics for quality checks

Read Counting
featureCounts or HTseq to generate read Count matrices for RNA-seq

Output: Gene-level count Matrix

DEG Analysis

Tools: DESeq2 or EdgeR for differential expression analysis

Outputs: --> Log2FC, adjusted pvalues

Data Package 1 from Summer internship for DEG analysis to get statistically significant DEGs

Mutation Analysis
Use GATK or Varscan for calling mutations from aligned genomic data

Annotate mutatations using ANNOVAR or SnpEff

Outs --> Per-Sample mutation data, Gene IDs with annotated mutations

Gene Set Enrichment Analysis GSEA

Input:
Ranked gene lists (eg. based on log2FC)

ClusterProfiler or my Volcano Plot using ggplot
